# Feldera

> Feldera is an incremental compute engine for running complex SQL data pipelines in real time. Instead of reprocessing whole datasets, it updates materialized views proportionally to the changes in the input data, powering use cases such as fraud detection, feature engineering, and real-time dashboards at low latency and cost. Feldera is built on the DBSP incremental computation theory and is available as open source, self-hosted enterprise, and a hosted online sandbox.

## APIs

- [Feldera API (REST)](https://docs.feldera.com/api/): The pipeline-manager REST API for creating, deploying, and interacting with SQL pipelines (60 operations across pipeline management, pipeline interaction, configuration, API keys, and metrics). Auth is bearer JWT or API key.
- [OpenAPI (verbatim)](https://raw.githubusercontent.com/feldera/feldera/main/openapi.json): OpenAPI 3.0.3 description of the Feldera API.
